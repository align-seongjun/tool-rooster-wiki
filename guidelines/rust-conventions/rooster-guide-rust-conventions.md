# Rust 코드 컨벤션

## 정적 분석

- `cargo build`/`cargo check`는 경고 0개를 목표로 한다.
- `cargo clippy`, `cargo fmt --check`를 커밋 전 실행한다.

## 모듈 구조

- 엔진/CLI 모드 분기는 단일 바이너리 안에서 이루어진다 ([ADR-001](../../adr/001-single-binary)). 서브커맨드 디스패치(`main.rs`)와 실제 로직(DB 접근, HTTP 핸들러, 스케줄링)은 분리한다 — 구체적 파일 분할은 Phase 1~2 구현 시 확정.

## 에러 처리

- 외부 경계(사용자 입력 파싱, 파일 I/O, DB 쿼리, HTTP 요청)에서만 명시적으로 에러를 다루고, 내부 로직에서는 불필요한 방어 코드를 추가하지 않는다.
- `unwrap()`/`expect()`는 테스트 코드나 "실패하면 안 되는" 초기화 단계(예: 설정 파싱 직후) 외에는 지양하고, `Result` 전파를 우선한다.

## 제약사항

- 새 의존성 추가는 최소한으로 유지 — 불필요한 추상화 금지 원칙에 따라 필요성이 확인된 시점에만 추가한다.
