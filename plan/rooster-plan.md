# rooster 개발 계획

> **통합 스냅샷**: 이 문서는 전체 계획을 한 파일에서 볼 수 있는 스냅샷입니다.
> 세분화 원본은 [plan/index](index)를 참조하세요.

MVP 범위는 엔진 + CLI. GUI 스파이크(Phase 6)는 엔진/CLI와 병렬 진행 가능하나 편의상 순서상 마지막에 배치. 상세는 [plan/overview](overview/rooster-plan-overview) 참조.

| Phase | 내용 | 플랫폼 | 상태 |
|-------|------|--------|------|
| [0](phase-0/rooster-plan-phase-0) | 프로젝트 셋업 | 개발 머신(macOS) | 진행 중 |
| [1](phase-1/rooster-plan-phase-1) | 데이터 모델 + 엔진 코어 | 개발 머신(macOS) | 시작 전 |
| [2](phase-2/rooster-plan-phase-2) | 로컬 HTTP API | 개발 머신(macOS) | 시작 전 |
| [3](phase-3/rooster-plan-phase-3) | CLI 클라이언트 | 개발 머신(macOS) | 시작 전 |
| [4](phase-4/rooster-plan-phase-4) | 스케줄링 + 알림 | 3개 OS | 시작 전 |
| [5](phase-5/rooster-plan-phase-5) | 엔진 생명주기 (OS 서비스 등록) | 3개 OS | 시작 전 |
| [6](phase-6/rooster-plan-phase-6) | GUI 스파이크 | 개발 머신(macOS), 브라우저 | 시작 전 |

각 Phase의 세부 작업 항목과 완료 기준은 개별 Phase 문서 참조. 진행 상태는 [progress.md](../progress)에서 추적.
