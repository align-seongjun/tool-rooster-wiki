# CLI 파일 입출력 (import/export)

## 개요

백업/추출을 염두에 두고 파일 입출력을 기본 사양으로 채택한다. 플래그로 하나씩 등록하는 방식이 아니라 파일을 통째로 읽어들이는 벌크 인서트가 기본이다. 포맷은 JSON을 우선 개발한다 — SQLite 스키마와 1:1 매핑이 쉽고 serde로 손실 없는 왕복(export → import)이 가능해 백업 신뢰성이 높다.

## 기능 요구사항

### FR-CLIIO-001: JSON export
- **우선순위**: P0
- **설명**: 사용자는 등록된 게임+숙제 전체를 JSON 파일로 덤프할 수 있다.
- **수용 기준**: `export --out backup.json` 실행 후 `{ "games": [...], "tasks": [...] }` 구조의 파일이 생성된다.

### FR-CLIIO-002: JSON import (백업 복원)
- **우선순위**: P0
- **설명**: `games` 배열이 채워진 파일을 import하면 게임은 자동 복원되고(이미 있으면 스킵), `tasks`가 참조하는 게임이 없으면 에러 처리한다.
- **수용 기준**: export로 만든 파일을 그대로 import하면 원래 상태로 왕복 복원된다. `tasks`가 참조하는 게임이 `games`에 없으면 import가 에러로 실패한다.

### FR-CLIIO-003: JSON import (신규 벌크 등록)
- **우선순위**: P1
- **설명**: 사용자가 `games` 섹션을 명시적으로 채운 신규 파일을 import하면 벌크 등록으로 동작한다. 별도 플래그 없이 백업 복원과 자연히 구분된다 — games 섹션 존재 여부가 시나리오를 가른다.
- **수용 기준**: `games`와 `tasks`를 직접 작성한 파일을 `import`하면 해당 게임/숙제가 새로 등록된다.

## 제약사항

- 다른 포맷(YAML/TOML) 지원은 필요성이 확인되면 차후 추가 — 초기 스코프 아님
