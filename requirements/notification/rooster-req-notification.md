# 마감 임박 알림

## 개요

마감 임박 숙제/이벤트를 OS 네이티브 토스트 알림으로 알린다. 순간적 이벤트 알림 수단이며, 상시 열람 수단인 오버레이 GUI(후순위)와는 목적이 다르다.

## 기능 요구사항

### FR-NOTIFY-001: 마감 임박 판정 및 알림 발송
- **우선순위**: P0
- **설명**: 엔진은 백그라운드에서 스케줄을 주기적으로 체크하고, 각 숙제의 `notify-before`(분 단위) 시점에 도달하면 OS 네이티브 토스트 알림을 발송한다.
- **수용 기준**: 등록된 숙제의 마감 시각 - `notify-before` 시점에 OS 알림이 실제로 표시된다.

### FR-NOTIFY-002: 알림 발송 이력 확인
- **우선순위**: P1
- **설명**: 사용자는 최근 알림 발송 이력을 `status` 커맨드로 확인할 수 있다.
- **수용 기준**: `status` 출력에 최근 알림 항목(시각, 게임명, 숙제명)이 표시된다 ([status](../status/rooster-req-status) 참조).

## 제약사항

- 외부 서버 없이 OS 네이티브 알림 API만 사용 (3개 OS 각각의 네이티브 방식)
- 알림 발송 여부는 엔진의 "마지막 스케줄 체크" 루프가 실제로 도는 것에 의존 — 루프가 멈추면 알림도 멈춤 ([lifecycle](../../architecture/lifecycle/rooster-arch-lifecycle) 참조)
