# 전체 개요

## 개요

게임 특화 일정 관리 유틸리티. 일일/주간/월간 반복 숙제와 기간 한정 일회성 이벤트를 등록·관리하고, 마감이 임박하면 OS 네이티브 알림으로 알려준다. 데스크톱 전용(Windows/macOS/Ubuntu), 로컬 알림만 사용하며 외부 서버는 두지 않는다.

## 기능 요구사항

### FR-OVERVIEW-001: 핵심 가치
- **우선순위**: P0
- **설명**: 사용자가 게임별 숙제를 등록해두면, 마감이 임박했을 때 놓치지 않고 알림을 받을 수 있다.
- **수용 기준**: 등록 → 마감 임박 알림 흐름이 CLI만으로 완전히 동작한다.

## 제약사항

- 모바일(iOS/Android)은 스코프 제외 — 백그라운드 상주 제약이 근본적으로 다름 ([platform](../platform/rooster-req-platform) 참조)
- 외부 서버 없이 로컬 알림만 사용
- 상황에 따라 불특정 다수 배포도 염두에 둠 ([distribution](../distribution/rooster-req-distribution) 참조)
