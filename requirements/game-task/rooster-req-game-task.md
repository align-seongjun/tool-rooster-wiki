# 게임/반복 숙제 등록 및 관리

## 개요

숙제는 반드시 게임에 종속된다 — 숙제 등록보다 게임 등록이 선행되어야 한다(참조 무결성). 반복 주기는 일일/주간/월간을 지원한다.

## 기능 요구사항

### FR-GAME-001: 게임 등록/조회/삭제
- **우선순위**: P0
- **설명**: 사용자는 게임을 이름으로 등록하고, 목록을 조회하고, 필요 시 삭제할 수 있다. 삭제 시 하위 숙제가 있으면 기본은 "N개 숙제도 같이 삭제할까요?" 인터랙티브 확인을 거치고, `--cascade` 플래그를 주면 확인 없이 게임+숙제를 일괄 삭제한다(스크립트/자동화 용도).
- **수용 기준**: `game add`/`game list`/`game rm [--cascade]`가 각각 동작하고, 하위 숙제가 있는 게임을 `--cascade` 없이 삭제하면 확인 프롬프트가 뜨며, `--cascade`를 주면 확인 없이 즉시 삭제된다.

### FR-GAME-002: 반복 숙제 등록
- **우선순위**: P0
- **설명**: 사용자는 게임에 속한 숙제를 일일/주간/월간 주기로 등록할 수 있다. 각 숙제는 시각(`--time`)과 마감 임박 알림 시점(`--notify-before`, 분 단위)을 갖는다.
- **수용 기준**: `add --game X --task Y --period daily|weekly|monthly --time HH:MM --notify-before N`으로 등록되고, 등록된 숙제가 `list`로 조회된다.

### FR-GAME-003: 숙제 완료 처리
- **우선순위**: P0
- **설명**: 사용자는 숙제를 완료 처리할 수 있다. 반복 숙제는 완료 처리 후 다음 주기에 다시 나타난다.
- **수용 기준**: `done <task-id>` 실행 후 해당 숙제가 완료 이력에 기록되고, 반복 숙제는 다음 주기 시점에 다시 미완료 상태로 조회된다.

### FR-GAME-004: 숙제 삭제
- **우선순위**: P1
- **설명**: 사용자는 등록한 숙제를 삭제할 수 있다.
- **수용 기준**: `rm <task-id>` 실행 후 해당 숙제가 `list`에서 더 이상 조회되지 않는다.
