# 기간 한정 일회성 이벤트

## 개요

반복 숙제와 별개로, 특정 마감 시각(deadline)을 갖는 일회성 일정을 등록·관리한다. 데이터 모델은 반복 숙제와 동일한 `tasks` 테이블을 공유하되 `period=once`로 구분된다.

## 기능 요구사항

### FR-ONCE-001: 일회성 이벤트 등록
- **우선순위**: P0
- **설명**: 사용자는 게임에 속한 일회성 이벤트를 특정 마감 시각과 함께 등록할 수 있다.
- **수용 기준**: `add --game X --task Y --period once --deadline <ISO8601> --notify-before N`으로 등록되고 `list`로 조회된다.

### FR-ONCE-002: 완료 후 처리
- **우선순위**: P1
- **설명**: 일회성 이벤트는 반복 숙제와 달리 완료 처리 후 다음 주기가 생성되지 않는다.
- **수용 기준**: `done <task-id>` 처리 후 해당 이벤트가 활성 목록에서 사라지고 다시 나타나지 않는다.

### FR-ONCE-003: 마감 경과 후 미완료 처리
- **우선순위**: P1
- **설명**: 마감이 지났는데 완료 처리가 안 된 일회성 이벤트는 자동으로 숨기거나 삭제하지 않고 "지남(overdue)" 상태로 계속 표시한다. 삭제는 사용자가 직접 한다.
- **수용 기준**: 마감 시각이 지난 미완료 일회성 이벤트가 `list --overdue`(또는 기본 `list`)에서 overdue 상태로 계속 조회되며, 시스템이 임의로 삭제하지 않는다.

## 제약사항

- 반복 숙제(`daily`/`weekly`/`monthly`)와 동일한 `add`/`list`/`done`/`rm` 커맨드를 공유하고 `--period`로만 구분 ([game-task](../game-task/rooster-req-game-task) 참조)
